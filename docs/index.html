Get set up

Work down the list. Skip anything you already have. Stuck? Put your hand up.

  1. Install the tools

    In PowerShell, then close and reopen it.

    winget install Git.Git OpenJS.NodeJS.LTS GitHub.cli
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    In Terminal, with Homebrew.

    xcode-select --install
brew install node gh uv

    Use your distro's package manager for git, gh and Node 18+.

    sudo apt install git gh nodejs npm
curl -LsSf https://astral.sh/uv/install.sh | sh

    You don't need to install Python. uv fetches the right version for you.

  2. Pick your coding agent

    Any of these works tonight. Already have one? Pick it and skip the install.

    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash

    Run claude once and sign in.

    npm install -g @openai/codex

    Run codex once and sign in.

    npm install -g @github/copilot

    Run copilot once and sign in with GitHub. You need a Copilot plan; the free one is fine.

    Install Cursor, Windsurf or OpenCode from its own website and open a terminal inside it.

  3. Install the skills

    claude plugin install mattpocock-skills@claude-plugins-official
    codex plugin marketplace add mattpocock/skills
codex plugin add mattpocock-skills@mattpocock
    copilot plugin marketplace add mattpocock/skills
copilot plugin install mattpocock-skills@mattpocock
    npx skills@latest add mattpocock/skills

    It asks which agent to install for. These are plain files you can edit; update them later with npx skills@latest update.

    Use one install method per agent. Doing two installs every skill twice.

  4. Make your own copy of the shop

    Create my copy on GitHub

    Then clone it. Swap in your GitHub name and the name you gave the repo.

    gh auth login
gh repo clone YOUR-NAME/YOUR-REPO
cd YOUR-REPO

  5. Set up the skills in your copy

    Start your agent in the repo folder, then run the setup skill.

    claude
/setup-matt-pocock-skills
    codex
Use the setup-matt-pocock-skills skill
    copilot
/setup-matt-pocock-skills
    Use the setup-matt-pocock-skills skill

    When it asks where issues go, pick GitHub if gh is signed in. Otherwise pick local files.

  6. Run the shop

    Terminal 1
    cd python-eshop/backend
uv sync
uv run python run.py
    Terminal 2
    cd python-eshop/frontend
npm install
npm run dev

    Open 127.0.0.1:4321. Sign in with demouser@perthai.com.au and Pass@word1.

You're ready when the shop shows products with pictures
